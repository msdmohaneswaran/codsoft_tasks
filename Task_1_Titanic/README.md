# Task 1 - Titanic Survival Prediction

## Objective

Build a machine learning model to predict whether a Titanic passenger survived or not.

## Dataset

The dataset contains passenger information such as age, gender, passenger class and fare.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning

Classification

## Steps

1. Load the Titanic dataset
2. Explore the data
3. Handle missing values
4. Preprocess the data
5. Split the data into training and testing sets
6. Train the machine learning model
7. Make predictions
8. Evaluate the model

## Target Variable

Survived

## Conclusion

The project demonstrates how machine learning can be used to predict passenger survival based on passenger information.
