# Task 2 - Movie Rating Prediction Using Python

## Objective

Build a machine learning model to predict movie ratings using movie-related information.

## Dataset

The dataset contains information about movies and their ratings.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm

Random Forest Regressor

## Steps

1. Load the movie dataset
2. Explore the data
3. Clean the data
4. Handle missing values
5. Select relevant features
6. Split the data into training and testing sets
7. Train the Random Forest model
8. Predict movie ratings
9. Evaluate the model

## Target Variable

Rating

## Evaluation Metrics

- MAE
- RMSE
- R2 Score

## Conclusion

The project demonstrates how machine learning can be used to predict movie ratings using movie-related features.
