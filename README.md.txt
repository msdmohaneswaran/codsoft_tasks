# Task 4 - Sales Prediction Using Python

## Objective

Build a machine learning model to predict sales based on advertising expenditure.

## Dataset

The dataset contains advertising expenditure for:

- TV
- Radio
- Newspaper

The target variable is Sales.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm

Linear Regression

## Steps

1. Load the advertising dataset
2. Explore the data
3. Check for missing values
4. Select input features
5. Split the data into training and testing sets
6. Train the Linear Regression model
7. Make sales predictions
8. Evaluate the model
9. Visualize the results

## Input Features

- TV
- Radio
- Newspaper

## Target Variable

Sales

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R2 Score

## Conclusion

The project demonstrates how Linear Regression can be used to predict sales based on advertising expenditure.
